# Awesome Korean IME [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

리눅스용 한글 입력기(IME)와 입력기 프레임워크 모음.

## 입력 엔진

- [fcitx5-hangul](https://github.com/fcitx/fcitx5-hangul) - Fcitx5용 한글 엔진. KDE 및 Wayland WM 환경에 권장.
- [ibus-hangul](https://github.com/libhangul/ibus-hangul) - IBus용 한글 엔진. GNOME 기본.
- [kime](https://github.com/Riey/kime) - Rust로 작성된 한글 전용 엔진. XIM/Wayland/GTK/Qt 프론트엔드 자체 제공.
- [nabi](https://github.com/libhangul/nabi) - XIM 서버 형태의 가벼운 한글 입력기. X11 전용.
- [nimf](https://github.com/hamonikr/nimf) - 독립 입력기 프레임워크 겸 엔진. HamoniKR 팀이 포크해 유지 중.
- [uim-byeoru](https://github.com/uim/uim) - uim 프레임워크의 한글 모듈(벼루).

## 레거시 / 비활성

- [imhangul](https://github.com/libhangul/imhangul) - GTK+ immodule 한글 입력기. 프레임워크 없이 직결.
- [qimhangul](https://packages.debian.org/jessie/qimhangul-common) - Qt용 한글 immodule.
- [scim-hangul](https://github.com/libhangul/scim-hangul) - SCIM용 한글 엔진. SCIM 자체가 비활성.
